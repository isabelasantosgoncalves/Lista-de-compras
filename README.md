# Despensa — lista de compras

Lista de compras que sabe o que tem em casa.

- **Em casa:** os itens que precisam estar sempre em casa, cada um marcado como Tem, Pouco, Acabou ou Agora não.
- **Verificar:** passa pelos itens um a um, arrastando o cartão (→ tem, ← acabou, ↑ pouco, ↓ agora não).
- **Lista:** junta o que acabou ou está no fim, mais os itens "só desta vez". Dá para levar em texto, imagem ou PDF.

Funciona sem internet e pode ser instalado no celular ("Adicionar à tela inicial"). Os dados ficam só no aparelho.

Fonte: [Shantell Sans](https://github.com/arrowtype/shantell-sans) (SIL Open Font License, ver `fonts/OFL-shantell-sans.txt`).
